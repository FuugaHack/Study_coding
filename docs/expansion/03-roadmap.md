# 03. 開発ロードマップ

各マイルストーンは「動くもの」をリリースできる単位にしている。完了条件を満たし、テストとレビューが通ったものだけを「完了」とする。

## 依存関係

```
M1 学習エンジン+ゲーミフィケーション基盤 ──┬─> M2 ゲーミフィケーション拡張 / スキルツリーマップ
   (サーバー採点・XP・ストリーク・解放)      ├─> M3 コード実行サンドボックス + AI 回答レビュー
                                              ├─> M5 用語学習 ─┐
                                              └─> M6 資格対策 <─┘ (SRS 共有)
M3 ──> M4 AI 問題レビュー / ワーカー分離 / コスト計測
M3, M4 ──> M7 開発工程コース・実践プロジェクト・AI メンター
M1, M2 ──> M8 モバイル (Expo)
```

## マイルストーン

### M1: 学習エンジン + ゲーミフィケーション基盤 【今回実装】 (#2)
| Issue | 内容 | 完了条件 |
|---|---|---|
| M1-1 | テスト基盤と CI | `pytest` が PostgreSQL に対して実行でき、GitHub Actions で backend テスト + frontend typecheck/build が走る |
| M1-2 | カタログのサーバー移行 | 28 コース/115 問が `app/content/catalog.json` から API 提供される。レスポンスに正解が含まれない。フロントの静的データを削除 |
| M1-3 | サーバー採点と回答ログ | choice / multiple-choice / code(穴埋め) をサーバーで採点。text は自己チェックとして記録。`question_attempts` に保存 |
| M1-4 | XP・レベル・ストリーク・コイン | `xp_events` 台帳 + `user_stats`。冪等。JST 日付でストリーク計算。DB レッスン提出にも XP 付与 |
| M1-5 | デイリークエスト | 3 種のクエストの進捗表示、達成時に自動で報酬付与 (1 日 1 回) |
| M1-6 | 前提コースによる解放 | `prerequisites` を満たすまでロック。進捗率・ステータスは実データから算出 |
| M1-7 | UI | ヘッダーにレベル/XP/ストリーク/コイン、回答時の報酬演出、ダッシュボードにクエスト |

### M2: ゲーミフィケーション拡張 (#3)
実装済み (詳細は `m2-design.md`): バッジ、ウィークリークエスト、ステージマップ、実力テストによる飛び級、ボス戦、ストリークフリーズ、マスコット。
残り (別 Issue): ダークモード、フレンド / リーグ。

当初の計画: バッジ/実績、ウィークリークエスト、ステージマップ (スキルツリー可視化)、実力テストによるスキップ、ボス戦 (コース総合問題)、ストリークフリーズ (コインで購入)、オリジナルマスコット、ダークモード、フレンド/任意参加リーグ。

### M3: コード実行サンドボックス + AI 回答レビュー (#4)
実装済み (詳細は `m3-design.md`): 隔離ランナー、コーディング問題のサーバー移行 (自動採点 10 問)、段階ヒント、AI レビュー (7 観点)、異議報告、DB レッスンの正解漏れ修正とサンドボックス採点。
残り: React / FastAPI / SQL などフレームワーク系の実行、gVisor の導入。

当初の計画: 隔離ランナー (ネットワーク遮断・CPU/メモリ/時間制限) でテストケース判定。AI レビューは観点別スコア (正確性/可読性/性能/セキュリティ/保守性/BP/設計意図) の構造化 JSON。段階ヒント (3 段階、正解は最後)。DB レッスンとカタログの統合、`LessonDetailResponse` の正解露出 (D5) 修正。

### M4: AI 問題レビュー・運用基盤 (#5)
問題品質レビュー (正確性/複数正解/陳腐化/難易度/重複/誤字) の結果を DB 保存し、基準未満は「要修正」として再レビュー。根拠として公式ドキュメント URL を必須化。AI 処理のワーカー分離、トークン/コスト計測、構造化ログ。

### M5: 用語学習 + 実力診断 (#6)
用語マスタ (意味/初心者向け/技術詳細/使用例/関連語/類似語との違い/図解)。フラッシュカード・選択・穴埋め・マッチング。SRS (SM-2) による復習。

### M6: 資格対策 (#7)
試験範囲マスタ (IT パスポート → 基本情報 → AWS CLF/SAA の順)。分野別演習、制限時間付き模試、分野別習熟度、試験日からの逆算計画。問題はオリジナル作成 (過去問の転載はしない)。

### M7: 開発工程コース・実践プロジェクト・AI メンター (#8)
18 工程のコース (判断理由を問う設問中心)。架空クライアント案件 (タスク管理 → EC → リアルタイムチャット)。AI が PM/テックリード/レビュアーを演じ、要件・コスト・拡張性・保守性の観点で設計判断を評価。キャリア別ロードマップ。

### M8: モバイルアプリ (#9)
`apps/mobile` (Expo + expo-router)。`packages/api-client` で API/型を共通化。プッシュ通知 (Expo Notifications)、リマインダー、オフライン (当日分のクイズをキャッシュし再接続時に送信)、触覚フィードバック。ストア申請は要承認。
